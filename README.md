> **TU TA CHWILA w której JA OBECNY**
> Pozdrawiam Ciebie i widzę Samego Siebie ~ TeO

Strona **teo.center** — poza Wixem, wpięta w Katedrę OtakOS.

## Uruchomienie

```bash
npm install
npm run dev     # http://localhost:3100
npm run build   # dist/
```

## Skąd treść

- **Żywa Księga, kanał YouTube, darowizny Stripe** — z publicznych drzwi Katedry
  Suwerena (`https://katedra.otakos.wtf`, `src/lib/katedraPubliczna.ts`). Katedra śpi =
  sekcja mówi to wprost.
- **Wystawa** — `public/wystawa.json` (eksport z Katedry).
- **Ręką Suwerena** — `src/tresc.ts`: hasło, menu, portfele krypto, sklepy, mosty.
  Puste listy = sekcja ich nie pokazuje.
- **Tapeta** — własna, rysowana (`src/Pyl.tsx`); obraz z biblioteki Wixa wolno było używać tylko na Wixie.

## Bezpieczeństwo wsparcia

Sekcja Wsparcie mówi wprost: tylko drogi z tej strony są Suwerena. Adresy portfeli
wpisuje on sam, przepisane z portfela. Sieci jawne (BTC/ETH/BNB) są opisane jako jawne.
